# flac-prep

本地 FLAC 批量整理命令行工具。读取已有标签，按 `歌名-歌手[专辑].flac` 导出，保留封面与歌词；缺内嵌歌词时，自动嵌入同目录同名 LRC。所有处理都写入独立输出目录，源文件保持不变。

当前支持 macOS/Linux、Python 3.10+，以本地 FLAC 及配套歌词、封面为输入。完整规则见 [SPEC-MUSICDL.md](SPEC-MUSICDL.md)。

## 安装

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

依赖包含 Mutagen、NumPy、Pillow、Python-soxr 和 imageio-ffmpeg。优先使用 PATH 中的 FFmpeg，否则使用 imageio-ffmpeg 随包提供的二进制。也可以用 `--ffmpeg /absolute/path/to/ffmpeg` 或环境变量 `FLAC_MGR_FFMPEG` 指定后端。libsoxr 重采样通过 Python 绑定执行，不要求 FFmpeg 自身编译 libsoxr。

项目无需 pip install，只安装依赖即可。当前已准备好 `.venv`，直接运行根目录的 `cli.py`。代码平铺在项目根目录：`cli.py` 负责命令入口，`core.py` 负责扫描、命名、标签和任务流程，`audio.py` 负责音频处理。

## 批量处理

输入可以是普通目录，无需保留 musicdl 的目录结构：

```text
music/
  1.flac
  1.lrc
  2.flac
  2.lrc
```

先预览（不创建输出目录、不写音频）：

```bash
.venv/bin/python cli.py preview
```

再导出：

```bash
.venv/bin/python cli.py export
```

默认输入为项目目录下的 `data/src`，输出为 `data/dest`，与启动命令时的工作目录无关。也支持显式路径：`python cli.py export /path/to/music -o /path/to/output`，以及单个 FLAC 输入。目录扫描递归进行，排除隐藏目录、符号链接及指定输出目录。文件名主体严格匹配，扩展名不区分大小写；不会把不同目录的歌词交叉配对。

本项目示例：

```bash
.venv/bin/python cli.py preview tmp/musicdl/musicdl_outputs -o data/dest
.venv/bin/python cli.py export tmp/musicdl/musicdl_outputs -o data/dest
```

可以添加 `--json` 输出机器可读的清单，`--compression 0..12` 指定 FLAC 压缩等级（默认 8）。不提供 pip 安装入口。

## 转换策略

| 输入 | 输出 |
| --- | --- |
| 24/192、24/96、24/88.2、16/96 | 16/44.1 |
| 24/48 | 16/48 |
| 24/44.1 | 16/44.1 |
| 16/48、16/44.1 | 保留原规格与 PCM |
| 低采样率、低位深 | 不自动提升；低位深且需要重采样时暂报不支持 |

- 高采样率由 libsoxr VHQ 转为 44.1 kHz，包含抗混叠滤波。
- 重采样和位深降低均在高精度处理中完成，最终量化到 16-bit 时添加一次 TPDF dither，默认无噪声整形。
- 检查重采样后的采样峰值；距离满幅不足 8 个 16-bit LSB 时，将峰值衰减至 -0.1 dBFS，并记录实际增益。此为采样峰值保护，不是真峰值限制器，也不保证后续设备 EQ 不发生削波。
- 不自动混音、裁静音、调整响度或使用限幅器。专辑统一增益与无缝接缝处理尚未实现。
- 无音频或元信息修改需求时直接复制；仅需补歌词/封面时在目标副本上修改标签，不重采样或重复加 dither。

## 标签、歌词与封面

- 必须已有非空 `TITLE`、`ARTIST`、`ALBUM`；否则报告 `needs_metadata`，不猜测歌曲身份。
- 目标名称来自这些标签，文件名中的不兼容字符会清理；标签本身不改写。多个歌手值用 `、` 连接。
- 缺内嵌歌词（包括空白字段）时，将同名 LRC 全文嵌入 `LYRICS`，保留时间戳和 offset；已有非空内嵌歌词不覆盖。
- 只输出 `.flac`；源 LRC 用于补写内嵌歌词，不复制或生成外部歌词文件。嵌入文本时移除 UTF-8 BOM。
- LRC 必须是 UTF-8（可带 BOM）。无法解码时报错；空 LRC 给出警告。编码转换参数留待后续实现。
- 保留内嵌 JPEG/PNG 封面原始数据；没有内嵌封面时，可以补入同名且唯一的 JPG/JPEG/PNG。
- 保留自定义标签；音频经过转换后移除旧 ReplayGain/R128/峰值字段，并记录被移除的字段。
- 歌词或封面缺失时可以导出并给出提示；损坏或有歧义的资源不会被静默忽略。

## 冲突、记录与重试

同批或目标目录已有重名时，像浏览器下载一样依次生成 `歌名-歌手[专辑].flac`、`歌名-歌手[专辑] (1).flac`、`歌名-歌手[专辑] (2).flac`。目标 FLAC 名称被占用时，选择下一个编号；已有文件不会被覆盖。成功导出后，输出目录旁的隐藏目录 `data/.flac-mgr/<输出路径标识>/` 保存成功记录和批次 JSON 报告；清单包含源文件与外部资源哈希、配置、目标哈希及音频处理参数，不复制歌词正文。

再次运行时，只有记录和所有文件校验一致才显示 `already_done`。若 LRC、源文件、配置或输出发生变化，会选取新的可用后缀，不覆盖旧版本。即使较早编号被移走，已有带后缀的成功输出仍能被识别，不会重复导出。

为避免覆盖，本版在本地输出目录内使用临时文件、独占任务锁和硬链接提交。请导出到支持硬链接的本地磁盘（例如 APFS/ext4），完成后再复制到播放器或 FAT/exFAT 存储卡。暂不直接导出到不支持硬链接的目标文件系统。

普通中断会清理临时目录；下次导出会核对未完成提交，只移除日志证明属于该任务且内容未改变的部分输出。强制结束进程可能留下隐藏的 `.flac-mgr-stage-*` 临时目录，可在确认没有任务运行后手动清理。

转换临时空间大约需要 `目标采样率 × 声道数 × 8 × 秒数` 字节的浮点文件，另加目标 FLAC；例如 5 分钟双声道 44.1 kHz 约需 212 MB 浮点临时空间。按文件依次处理，不将整个音乐库读入内存。

退出码：`0` 成功或可接受的跳过（如已经完成、未配对 LRC），`1` 有文件失败或冲突，`2` 命令/环境错误，`130` 用户中断。警告仍会展示在输出和报告里。

## 验证

音频在导出时完整解码校验，并核对 FLAC 音频 MD5（常规 8/16/24/32-bit 且 STREAMINFO 提供校验值时）。可运行 `python cli.py preview` 检查输入、目标规格及文件名。

真实样本《爱情转移》已验证：24/192 转为 16/44.1，文件由约 157.3 MB 降至 27.8 MB，原始文件不变，封面及已有内嵌歌词保留。实际大小随音频和压缩配置变化。
